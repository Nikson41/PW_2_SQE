# 🎮 Хрестики-нулики (Tic-Tac-Toe)

Простий графічний застосунок гри **«Хрестики-нулики»**, розроблений мовою **Python** з використанням бібліотеки **Tkinter**.

---

## 📋 Опис проєкту

Програма реалізує класичну гру «Хрестики-нулики» для двох гравців.

Основні можливості:

* почергові ходи гравців **X** та **O**;
* автоматичне визначення переможця;
* визначення нічиєї;
* блокування поля після завершення гри;
* можливість почати нову гру;
* простий та зрозумілий графічний інтерфейс.

## 🚀 Запуск проєкту


### Запуск програми

```bash
python tictactoe_errors.py
```

---

## 🧪 Запуск тестів

### unittest

```bash
python -m unittest test_tictactoe.py
```

### pytest

```bash
pytest -v
```
